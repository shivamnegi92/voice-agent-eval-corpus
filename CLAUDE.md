# CLAUDE.md - voice-agent-eval-corpus

Context for AI agents working in this repo.

## What this is

Public companion resource to an arXiv preprint on real-time voice agent
evaluation ([2609.30798](https://arxiv.org/abs/2609.30798)). Ships
**metadata for 128 sources in the local revision** (cutoff 2026-10-02) plus **TRG** (Timing-Recovery-Grounded): a
minimum reporting standard, a compliance checker, a pip-installable pipeline
(`trg_eval/`), and a baseline leaderboard built from published figures.

- **Public:** `github.com/shivamnegi92/voice-agent-eval-corpus`
- **Hugging Face Space:** `huggingface.co/spaces/shivamnegi92/trg-voice-agent-eval`
- **Author:** Shivam Negi, Northeastern University, `negi.sh@northeastern.edu`
- Source repo for the paper is `SLM_PAPER`, which is **private** and lives at
  `../SLM_PAPER` locally.

The expanded snapshot and TRG report version 2 are prepared locally only.
No new release, arXiv revision, Zenodo record or live demo deployment has been
published. Existing examples remain legacy reports; preserve their measured
values and benchmark comparability.

## The one rule that matters

**Never commit a PDF here.**

A PDF-text audit finds **1 of 128** paper-scoped grants. The other 127 are
unspecified in the PDF, not necessarily arXiv-default. Licences for referenced
datasets/models do not license the paper. No PDFs may be committed regardless
of classification.

This is enforced twice, deliberately:
- `.gitignore` blocks `*.pdf` and `pdfs/`
- `.github/workflows/validate.yml` fails CI if any `*.pdf` is tracked

Instead of the papers, we ship their **SHA-256 hashes**. `fetch_corpus.py`
downloads from the original hosts and verifies each one, which makes the
corpus auditable without hosting anything.

## Layout

```
corpus/    voice_agent_corpus.csv|.json  128 rows, 19 core fields
           schema.md                     field definitions
           reconciliation.md             how 51 yaml -> 41 PDFs -> 38 primary
           licence_audit.csv             per-source redistribution status
           join_overrides.yaml           human-verified filename->bibkey pairs
           leaderboard.md|.csv           generated by trg-leaderboard, do not hand-edit
trg_eval/  validator.py, leaderboard.py, cli.py   installable pipeline (pyproject.toml)
scripts/   fetch_corpus.py               rebuild local PDFs, hash-verified
           validate_trg.py               thin CLI wrapper around trg_eval.validator
           build_leaderboard.py          thin CLI wrapper around trg_eval.leaderboard
trg/       trg_report_template.yaml            fillable
           trg_example_nemotron.yaml           worked example, self-reported figures
           trg_example_openai_realtime.yaml    worked example, tau-Voice-benchmarked
           trg_example_gemini_live.yaml        worked example, tau-Voice-benchmarked
           trg_example_grok_voice.yaml         worked example, tau-Voice-benchmarked
hf_space/  core.py, template.html, build_index.py  -> index.html (live HF Space)
```

The three tau-Voice-benchmarked examples share one source paper
(arXiv:2603.13686) so they're comparable: same evaluator, same conditions,
same task-completion protocol. Don't add a fourth baseline from a different
benchmark into that trio without flagging the comparability difference.

## Counts that must hold

**128 rows = 124 primary + 3 positioning + 1 method.** The 124 split
10/6/13/70/19/6 across six legacy artifact-type groups. Two-axis taxonomy
codes are recorded in `corpus/taxonomy_coding.yaml`.

CI enforces the explicit reviewed `revision` totals, full CSV/JSON equality,
no duplicate `paper_id` or `pdf_sha256`,
every identifier resolvable (`arXiv:` / `doi:` / `aclanthology:` prefixed).

## Regenerating

This repo is **generated**, not hand-edited. Source of truth is
`../SLM_PAPER/survey-paper-voice-agent-research/`:

```bash
cd ../SLM_PAPER/survey-paper-voice-agent-research
~/.venvs/voice-survey/bin/python scripts/build_corpus.py     # -> voice_agent_corpus.csv
~/.venvs/voice-survey/bin/python scripts/audit_licences.py   # -> licence_audit.csv
```

Then copy `voice_agent_corpus.csv|.json`, `join_overrides.yaml`,
`licence_audit.csv` and `taxonomy_coding.yaml` from `corpus_build/`. Editing
the CSV here directly will be overwritten on the next build.

## Local checks before pushing

```bash
python3 scripts/validate_trg.py trg/trg_report_template.yaml   # must FAIL (exit 1)
python3 scripts/validate_trg.py trg/trg_example_nemotron.yaml  # must PASS (exit 0)
python3 scripts/build_leaderboard.py                           # must list 4 systems
git ls-files '*.pdf' | wc -l                                   # must be 0
```

The template failing is correct behaviour: a blank report is not compliant.

Missing `reporting_version` means version 1. Version 2 requires timing anchors
and appropriateness, recovery state/protocol, no-action policy and trace evidence,
and shared conditions. Validate reporting structure, not performance thresholds;
equal disrupted and undisrupted results are valid. Do not fill legacy examples
with unreported measurements. The Space's vendored validator also retains its
demo-specific `format_report_html` function; do not replace it blindly with
the CLI module. Rebuild local `hf_space/index.html` after updating its assets,
but deployment requires separate authorisation.

## Things not to get wrong

- **Citation status is a preprint, not peer reviewed.** `CITATION.cff` and
  the README cite arXiv:2609.30798 as a preprint. Do not upgrade to a journal
  `@article` entry until it is genuinely accepted somewhere.
- **Identifiers come from `references.bib` in the private repo**, which is
  authoritative. `sources.yaml` there is an incomplete first-pass log and has
  at least one stale identifier. Do not source identifiers from it.
- **Hash mismatches are not necessarily bugs.** arXiv serves the latest
  version, so an author revision legitimately changes bytes. It means you do
  not have the artefact the survey analysed.
- **`corpus/leaderboard.md`/`.csv` are generated files.** Edit the
  `trg/trg_example_*.yaml` sources and rerun `trg-leaderboard`, not the
  generated files directly.
- **`hf_space/` must stay in sync with the live Space.** The Space is a
  static page running plain Pyodide (NOT Gradio-Lite: every Lite build
  crashed on `import gradio` in Sept 2026 via huggingface-hub -> filelock ->
  `os.link`). `core.py` holds the UI-agnostic logic; `template.html` is the
  UI; `build_index.py` embeds the .py/.yaml files into `index.html`. It
  vendors copies of `trg_eval/validator.py`/`leaderboard.py`. After changing
  either, copy into `hf_space/`, run `python3 hf_space/build_index.py`, and
  re-push `index.html` with `huggingface_hub`. `app.py` is an optional
  server-backed Gradio UI over the same `core.py`; the Space does not use it.
- **`export GH_HOST=github.com` for `gh`** if it defaults to an internal GHE host.
